# DSH 插件中心 · 开发计划

> 按「先数据管道 → 再列表页 → 再详情页 → 再交互 → 最后部署」的依赖顺序推进。
> 每阶段结束都有可运行、可验证的产物。

---

## Phase 0 · 项目脚手架
- [ ] 初始化 Vite + React + TS 项目，接 Tailwind CSS、React Router。
- [ ] 目录约定：`src/`（前端）、`scripts/`（爬虫）、`public/plugins/`（爬取的图片）、`data/plugins.json`。
- [ ] 配置 `GITHUB_TOKEN`（`.env`，入 `.gitignore`）。
- **验收**：`pnpm dev` 能起空首页；`pnpm crawl` 空跑成功。

## Phase 1 · 数据管道（爬虫）
- [ ] 用 GitHub Search API 拉取 `topic:dsh-plugin` 全量仓库，分页落盘 `repos.json`。
- [ ] 每仓库拉 README（raw）+ package.json（判 `dsh.bundle`）。
- [ ] 提取 `intro`（description 优先，兜底 README 首段）。
- [ ] 提取安装命令（4 级优先级）与多步安装步骤。
- [ ] 解析并下载图片到 `public/plugins/<owner>/<repo>/`，重写引用；过滤徽章/视频。
- [ ] 推断 `type` 与 `category`，合并输出 `plugins.json`。
- [ ] 增量缓存：按 `updatedAt` 跳过未变仓库；支持 `--force`。
- **验收**：`plugins.json` 覆盖 900+ 仓库，抽查 10 个的简介/安装命令/图片正确。

## Phase 2 · 列表页
- [ ] 顶部搜索栏（防抖、名称/描述/标签匹配）。
- [ ] 筛选栏：分类 / 类型 / 语言；排序：Stars · 最近更新 · 名称。
- [ ] 插件卡片组件（名称 + 徽标 + 简介 + Stars + 语言 + 时间 + 复制安装）。
- [ ] 分页 + URL 同步筛选参数。
- **验收**：搜索/筛选/排序/分页在浏览器中全链路可用。

## Phase 3 · 详情页
- [ ] 路由 `/plugin/:owner/:repo`，从 `plugins.json` 取数。
- [ ] 头部元信息区 + 仓库外链。
- [ ] 安装命令区（代码块 + 一键复制 + 多步步骤折叠）。
- [ ] 精简介绍区。
- [ ] 图片画廊（灯箱放大、无图占位）。
- **验收**：从列表点进详情，命令可复制、图片可看。

## Phase 4 · 交互与体验打磨
- [ ] 深色模式、响应式（移动端筛选抽屉）。
- [ ] 加载态/空态/错误态；图片懒加载。
- [ ] 复制按钮反馈、键盘可达性（a11y）。
- **验收**：桌面 + 手机宽度均正常；无控制台报错。

## Phase 5 · 数据保鲜与部署
- [ ] GitHub Action：定时重跑爬虫 → 重建 → 部署（默认每日）。
- [ ] 静态部署到目标平台（GitHub Pages / Vercel / 自托管 Nginx）。
- [ ] README（项目说明 + 本地开发 + 爬虫用法）。
- **验收**：线上可访问，插件数与 GitHub 基本同步。

## 里程碑
| 里程碑 | 产物 | 可验证 |
|---|---|---|
| M1 数据就绪 | `plugins.json` + 图片 | 900+ 条目、抽查正确 |
| M2 列表可用 | 首页列表 + 搜索筛选 | 浏览器可筛可搜 |
| M3 详情可用 | 详情页 + 安装 + 图片 | 命令复制、图片查看 |
| M4 上线 | 线上站点 + 定时刷新 | URL 可访问、数据保鲜 |

## 风险与对策
| 风险 | 对策 |
|---|---|
| GitHub API 限流 | 必带 token；增量缓存；爬取间隔 + 重试退避 |
| 917 仓库良莠不齐 | `type` 分类 + 默认过滤 + 手动覆盖表 |
| 安装命令形式多样 | 4 级提取 + 兜底自动生成，人工可覆盖 |
| 图片失效/外链 | 下载本地托管，跳过视频与徽章 |
| 数据过期 | CI 定时重爬 |
